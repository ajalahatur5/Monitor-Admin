Masuk sebagai Admin

Gunakan username admin (contoh: admin1) dan password yang sudah dibuat di Supabase Authentication. Panel ini hanya akan menampilkan data semua pengguna kalau akun ini sudah didaftarkan sebagai admin di database.

Tetap jangan bagikan email/password admin ke orang lain, dan cabut akses admin (hapus dari tabel admin_users) kalau sudah tidak dipakai.
